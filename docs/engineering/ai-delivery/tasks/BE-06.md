## Method

Strict TDD per implementation unit: write or activate the approved failing
test, run it and record the expected failure, implement the smallest code that
satisfies the approved contract, rerun the focused test, run the neighbouring
regression set, and continue only when green. One bounded logical commit per
unit or sub-unit. Tests run only against a disposable local PostgreSQL 17 and
Redis; nothing contacts Crossref or any production system.
